# Guia Casa Terras Altas

Site estático (guia de hóspedes) da **Casa Terras Altas** — Campos do Jordão: restaurantes,
atrações e informações da casa, com dados e fotos reais de cada lugar.

**Passo a passo completo, do zero até publicar (para leigos): [LEIA-ME.md](LEIA-ME.md)**

| Página | Conteúdo |
|---|---|
| `index.html` | Restaurantes (filtro por categoria) |
| `o_que_fazer.html` | Atrações (filtro por modalidade) |
| `sobre_a_casa.html` | Anfitriões, avaliações dos hóspedes, como chegar, informações úteis |

Rodar localmente: `py -3 -m http.server 8000` e abrir http://localhost:8000
Backup do projeto: `py -3 fazer_backup.py`
